# ds_store_exploit 使用说明

> 来源: [wilesanGH/ctf-web](https://github.com/wilesanGH/ctf-web) 内嵌脚本,已完善

## 依赖

```
pip install requests ds_store
```

## 命令

```bash
python ds_store_exploit.py --selftest                # 自测(本地HTTP+生成DS_Store)

python ds_store_exploit.py -u http://target.com/     # 远程: 下载 .DS_Store 解析并递归发现
python ds_store_exploit.py -u http://t/ -o found.txt -d 2   # 保存结果, 限深 2
python ds_store_exploit.py -f .DS_Store              # 本地: 直接解析已有文件
python ds_store_exploit.py -f .DS_Store --grep flag  # 只显示含关键词的条目
```

## 参数

| 参数 | 说明 |
|------|------|
| `-u URL` | 目标站点根 URL(自动请求 `<路径>/.DS_Store`) |
| `-f FILE` | 本地 .DS_Store 文件 |
| `-d N` | 递归深度(默认 3) |
| `-o FILE` | 发现的 URL 保存文件 |
| `--grep KEY` | 关键词过滤(不区分大小写, 如 flag/secret/backup) |

## 输出

```
[*] 扫描: http://target/.DS_Store
[+] 发现: secret.txt
[+] 发现: backup/
[+] 已保存 12 条 -> found.txt
```

发现 `flag.*` / `backup` / `*.sql` 等直接下载验证。
