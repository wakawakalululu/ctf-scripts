# php_class_brute 使用说明

> 来源: [wilesanGH/ctf-web](https://github.com/wilesanGH/ctf-web) 内嵌脚本,已完善(属性名爆破阶段)

## 依赖

```
pip install requests
```

## 命令

```bash
python php_class_brute.py --selftest                       # 自测(本地模拟靶场)

# 第一步: 类名字典爆破(内置 32 个常见类名)
python php_class_brute.py -u http://target/vuln.php -p p

# 第二步: 已知类名后爆破属性名
python php_class_brute.py -u http://t/vuln.php -p p --class Admin

# 自定义字典 / 命中特征串
python php_class_brute.py -u http://t/x -p p -w classes.txt --marker "Trying to access"
```

## 参数

| 参数 | 说明 |
|------|------|
| `-u URL` | 漏洞页面 |
| `-p PARAM` | payload 参数名(默认 p) |
| `-w TXT` | 类名字典文件(每行一个) |
| `--class NAME` | 已知类名 → 切换为属性名爆破 |
| `--props a,b,c` | 属性名字典(默认内置 23 个) |
| `--marker STR` | 类名命中额外特征(响应含它即算命中) |

## 判定依据

| 响应 | 含义 |
|------|------|
| `unserialize(): Error at offset` | 类名不存在 |
| 无 offset 报错 / 出现别的 Notice | 类名可能正确 |
| `Undefined property: X::$a` | 属性名不存在 |
| 无 Undefined 报错 | 属性名可能正确 |

两阶段结果拼接后用 [PHP反序列化wakeup绕过/wakeup_bypass.py](../PHP反序列化wakeup绕过/wakeup_bypass.py) 生成完整 payload。
