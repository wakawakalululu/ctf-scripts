# dirscan 使用说明

> 参考: [maurosoria/dirsearch](https://github.com/maurosoria/dirsearch)(轻量实现)

## 依赖

```
pip install requests
```

## 命令

```bash
python dirscan.py --selftest                 # 自测(本地起临时HTTP服务)

python dirscan.py -u http://target/          # 内置 25 个常见路径词表
python dirscan.py -u http://target/ -w dict.txt          # 自定义字典
python dirscan.py -u http://target/ --ext php,bak        # 词表追加扩展名
python dirscan.py -u http://target/ -t 20 --ok 200,301,403
```

## 参数

| 参数 | 说明 |
|------|------|
| `-u URL` | 目标根 URL |
| `-w TXT` | 字典文件(每行一个路径) |
| `--ext php,bak` | 每个词条追加扩展名 |
| `-t N` | 并发线程数(默认 10) |
| `--ok 200,...` | 视为存在的状态码 |

## 输出

```
[200]     19  http://target/secret.txt
[301]    312  http://target/admin
共 2 个命中
```
