# Git 泄漏解析 使用说明

> 来源: [wilesanGH/ctf-web](https://github.com/wilesanGH/ctf-web) 内嵌脚本,已完善(填充计算/SHA/校验和)

## 脚本一:git_index_parse(.git/index 解析)

### 依赖

```
无(纯标准库)
```

### 命令

```bash
python git_index_parse.py --selftest               # 自测

python git_index_parse.py .git/index               # 列出被跟踪文件路径
python git_index_parse.py .git/index --sha         # 同时显示对象哈希前12位
python git_index_parse.py .git/index --check       # 验证 SHA1 校验和(检测截断)
```

### 输出

```
版本: 2  条目: 5
  86f7e437faa5  a
  d14cedb3ed4e  flag.php
```

配合恢复源码: `git cat-file -p <sha>` 或用 [GitTools/GitHacker](https://github.com/internetwache/GitTools) 全量还原。

## 脚本二:git_dump_batch(批量 dump + flag 搜索)

### 依赖

```
pip install git-dumper     # 系统命令
```

### 命令

```bash
python git_dump_batch.py --selftest                        # 自测(仅本地逻辑)

python git_dump_batch.py -t http://a/.git/ http://b/.git/  # 多目标批量 dump
python git_dump_batch.py -f targets.txt --pattern "flag{"  # 目标文件 + 自定义模式
python git_dump_batch.py -t http://a/.git/ --jobs 10 -o out_dir
```

### 输出

```
[FLAG] git_dumps/dump_1/index.php: flag{d4mp_5c4n_0k}
[+] 完成 2 个目标, 命中 1 处
```
