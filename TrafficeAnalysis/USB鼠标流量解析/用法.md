# usb_mouse 使用说明

> 参考: [P001water/UsbmiceCracker](https://github.com/P001water/UsbmiceCracker) 的通用做法实现

## 依赖

```
pip install pillow
# pcap 输入方式另需系统安装 Wireshark(tshark)
```

## 命令

```bash
python usb_mouse.py --selftest                        # 自测

# 文本输入(每行一段 hex, 如 wireshark 导出的 usb.capdata / Leftover Capture Data)
python usb_mouse.py -f usbdata.txt                    # 连线轨迹 -> mouse.png
python usb_mouse.py -f usbdata.txt --mode click       # 只画左键按下点(画图题)
python usb_mouse.py -f usbdata.txt --mode both -s 5   # 轨迹+点击叠加, 放大5倍

# pcap 输入(自动调 tshark 提取 usb.capdata / usbhid.data 字段)
python usb_mouse.py -p capture.pcapng -o out.png
```

## 参数

| 参数 | 说明 |
|------|------|
| `-f TXT` | usbdata 文本文件 |
| `-p PCAP` | pcap/pcapng 文件 |
| `--skip N` | 每行取第 N 字节起的 3 字节(默认 0 = button,dx,dy) |
| `--mode path|click|both` | path=连线, click=左键点, both=叠加 |
| `-s N` | 放大倍数(默认 3) |
| `-o PNG` | 输出图片路径(默认 mouse.png) |

## 数据格式

每行一段 HID 报文 hex, 前 3 字节依次为 `[button][dx][dy]`; dx/dy 按 8 位有符号处理。
4 字节 Leftover 数据直接用默认 `--skip 0`; 若报文前面有头部字节则增大 `--skip`。

## 输出

```
报文数: 342, 轨迹点: 342, 左键点: 12
已生成: mouse.png 尺寸: (800, 600)
```

flag 一般是轨迹画出的字/图形, `--mode click` 与 `--mode path` 各试一次。
