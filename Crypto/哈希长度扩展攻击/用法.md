# hash_ext 使用说明

> 参考: [iagox86/hash_extender](https://github.com/iagox86/hash_extender)(纯 py3 实现, 无依赖)

## 依赖

```
无(纯标准库)
```

## 命令

```bash
python hash_ext.py --selftest        # 自测

python hash_ext.py -f md5 -d "?user=guest" -s <已知签名hex> -a "&user=admin" -l 16
python hash_ext.py -f sha1 -d "..." -s <签名> -a "..." --list 8,12,16,20,32
```

## 参数

| 参数 | 说明 |
|------|------|
| `-f md5|sha1` | 哈希函数 |
| `-d DATA` | 已知的 data(secret 之后的部分) |
| `-s SIG` | 已知签名 md5(secret+data) |
| `-a APPEND` | 要追加的内容 |
| `-l N` | SECRET 字节长度(已知时) |
| `--list 1,2,...` | SECRET 长度未知时依次尝试 |

## 输出

```
secret_len=16
  sig  = <新签名hex>
  tail = <hex, 含 %00 补齐段>
  data 提交格式: <原data> + tail (URL编码后拼接)
```

提交方式: 把 `data + tail` 整体 URL 编码后发给服务端, 签名换成 `sig`。
