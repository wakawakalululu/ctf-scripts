# tea_xtea 使用说明

## 依赖

```
无(纯标准库)
```

## 命令

```bash
python tea_xtea.py --selftest     # 自测

# 解密
python tea_xtea.py --algo xtea -a d -k 0123456789abcdef0123456789abcdef -c <hex密文>
# 加密
python tea_xtea.py --algo tea -a e -k mysecretkey16b -p 4142434445464748
```

## 参数

| 参数 | 说明 |
|------|------|
| `--algo tea|xtea` | 算法 |
| `-a e|d` | 加密/解密 |
| `-k` | 16 字节密钥(32 位 hex 或 ≤16 字节字符串, 不足补 \\0) |
| `-c / -p` | hex 密文 / hex 明文(长度须为 8 的倍数, 多块按 ECB 顺序) |
| `--delta` / `--rounds` | 题目改过参数时指定(默认 0x9E3779B9 / 32) |

## 输出

hex 字符串(加密输出密文, 解密输出明文)。

逆向题里若反汇编发现 `0x9E3779B9` 常量与 `<<4/^>>5` 结构, 即为 TEA 系, 按 `--delta/--rounds` 对应。
