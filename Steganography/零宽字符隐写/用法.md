# zwstego 使用说明

> 参考: [ridpath/ZeroWidthStego](https://github.com/ridpath/ZeroWidthStego)、[330k unicode_steganography](https://330k.github.io/misc_tools/unicode_steganography.html)

## 依赖

```
无(纯标准库, py3)
```

## 命令

```bash
python zwstego.py                                  # 自测

# 编码: 把 secret 藏进载体文本
python zwstego.py -e "这里是载体" --secret "flag{zws}"
python zwstego.py -f cover.txt --secret "flag" -o stego.txt   # 从文件读载体

# 解码: 提取文本中的零宽密文
python zwstego.py -d stego.txt
python zwstego.py -d "直接粘贴的文本"
```

## 参数

| 参数 | 说明 |
|------|------|
| `-e CARRIER` | 载体文本(密文附加在载体末尾) |
| `-f TXT` | 载体文件(与 -e 二选一) |
| `--secret TEXT` | 要隐藏的内容 |
| `-d TXT` | 解码目标(文件路径或直接文本) |
| `-o TXT` | 编码结果写入文件 |

## 字符映射

`U+200B`=0, `U+200C`=1, `U+200D`=字节分隔, `U+FEFF`=密文边界。
其他工具/网站编的零宽密文格式不同时, 先 `xxd` 看用了哪些零宽字符再对映射。

## 输出

解码打印隐藏内容; 无密文时打印 `(未发现零宽密文)`。
