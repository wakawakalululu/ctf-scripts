# qr_decode 使用说明

## 依赖

```
pip install opencv-python        # 引擎1(首选)
pip install pyzbar               # 引擎2(可选备用)
pip install qrcode               # 仅自测需要
```

## 命令

```bash
python qr_decode.py --selftest          # 自测(qrcode 生成 -> cv2 解码)
python qr_decode.py qr.png              # 解码
python qr_decode.py qr.png --binarize 128   # 阈值二值化后再试(污损/灰图)
python qr_decode.py small.png --scale 3     # 小图放大后解码
```

## 参数

| 参数 | 说明 |
|------|------|
| `image` | 图片路径 |
| `--binarize N` | 灰度阈值二值化(0=不处理) |
| `--scale N` | 放大倍数 |

## 输出

```
[cv2-multi] flag{qr_roundtrip}
```

解不出时按顺序试: `--scale 3` → `--binarize 100/128/180` → 截取二维码区域单独解码。
