# img_solve 使用说明

> 来源: [SourceLizi/ctf-toolbox](https://github.com/SourceLizi/ctf-toolbox)(py3 重写)

## 依赖

```
pip install pillow
```

## 命令

```bash
python img_solve.py --selftest                              # 自测

python img_solve.py img_dump.mem -W 150 -H 600              # 灰度 150x600, 行优先
python img_solve.py img_dump.mem -W 100 -m rgb              # RGB(高度自动算)
python img_solve.py img_dump.mem -W 150 -H 600 --major col  # 列优先(原版行为)
python img_solve.py img_dump.mem -W 150 --offset 0x40 -s 4  # 跳过64字节头, 放大4倍
python img_solve.py img_dump.mem -W 150 -H 600 --save out.png  # 保存不弹窗
```

## 参数

| 参数 | 说明 |
|------|------|
| `file` | dump 的原始内存文件 |
| `-W / -H` | 宽/高; `-H` 省略时按剩余数据自动计算 |
| `-m gray|rgb` | 颜色模式(默认 gray, 1字节/像素) |
| `--offset` | 数据起始偏移(支持 0x 十六进制) |
| `--major row|col` | row=行优先, col=列优先(原版脚本行为) |
| `-s N` | 放大倍数 |
| `--save PNG` | 保存文件; 不加则弹窗显示 |

## 尺寸猜测

宽高未知时用 `-W` 试 16/32/50/100/150 等常见值, 或 `W*H ≈ 文件字节数`(gray)。
