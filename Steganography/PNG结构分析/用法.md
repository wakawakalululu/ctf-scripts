# png_analyze 使用说明

> 来源: [wilesanGH/ctf-web](https://github.com/wilesanGH/ctf-web) 内嵌脚本(pngcheck 手册 + pillow 手册)合并完善

## 依赖

```
无(list/extract/fix-crc 纯标准库; 仅自测需要 pillow)
```

## 命令

```bash
python png_analyze.py --selftest                # 自测

python png_analyze.py list image.png            # 列出全部块(类型/长度/offset/CRC状态)
python png_analyze.py fix-crc image.png         # 修复全部错误 CRC -> image.fixed.png
python png_analyze.py fix-crc image.png -o ok.png
python png_analyze.py extract image.png tEXt    # 提取指定类型块内容(flag 常藏 tEXt/zTXt)
```

## 子命令

| 子命令 | 说明 |
|------|------|
| `list` | 遍历数据块; tEXt/zTXt 块直接预览内容; CRC 错误标 `BAD(应为 xxx)` |
| `fix-crc` | 重算并写入正确 CRC(宽高爆破/块修改后常用), 自动输出 `.fixed.png` |
| `extract TYPE` | 输出指定类型块原始字节(如 `tEXt`、`zTXt`、`IDAT`) |

## 输出
