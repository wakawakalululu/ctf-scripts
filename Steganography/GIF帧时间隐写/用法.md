# gif_frames 使用说明

## 依赖

```
pip install pillow
```

## 命令

```bash
python gif_frames.py --selftest            # 自测
python gif_frames.py -f anim.gif           # 打印每帧延时
python gif_frames.py -f anim.gif --save frames_dir/   # 逐帧导出 PNG
python gif_frames.py -f anim.gif --odd     # 只列延时离群的帧
```

## 参数

| 参数 | 说明 |
|------|------|
| `-f GIF` | gif 文件 |
| `--save DIR` | 逐帧导出 PNG |
| `--odd` | 只显示延时离群帧(自动中位数±3MAD 判定) |

## 输出

```
frame 0: duration=100ms
frame 2: duration=800ms  <-- 离群
已导出 4 帧 -> frames_dir/
```

flag 常见藏法: 离群延时帧本身是 flag 图、或长/短延时序列编码 0/1。
