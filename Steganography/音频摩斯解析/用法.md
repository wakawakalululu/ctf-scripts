# audio_morse 使用说明

## 依赖

```
无(纯标准库 wave, py3)
```

## 命令

```bash
python audio_morse.py --selftest            # 自测(生成含 SOS 的 wav 并解码)

python audio_morse.py secret.wav            # 解码输出明文
python audio_morse.py secret.wav --unit 0.06    # 自动判定失准再手动指定单位时长(秒)
```

## 参数

| 参数 | 说明 |
|------|------|
| `file` | wav 文件 |
| `--unit SEC` | 点时长(单位); 不指定则自动取最短"通" |

## 输出

```
摩斯 : ... --- ... / ... --- ...
明文 : SOS SOS
```

判定不准时先听/看波形确认音调间隔比例(点:划:间隔 = 1:3:1/3), 再 `--unit` 指定。
