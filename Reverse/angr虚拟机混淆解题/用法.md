# burforce_vm 使用说明

> 来源: [SourceLizi/ctf-toolbox](https://github.com/SourceLizi/ctf-toolbox)(地址参数化)

## 依赖

```
pip install angr    # 建议 Linux/WSL
```

## 命令

```bash
# find=成功分支地址, avoid=失败分支地址(逗号分隔), 地址来自 IDA / objdump -d
python burforce_vm.py ./SimpleVM --find 0x080488BB --avoid 0x08048907,0x080486E1

# 把解出的输入(stdin)保存到文件
python burforce_vm.py ./SimpleVM --find 0x080488BB --avoid 0x08048907 --stdin flag.bin
```

## 参数

| 参数 | 说明 |
|------|------|
| `binary` | 目标 ELF |
| `--find` | 成功分支地址(必填, 支持 0x) |
| `--avoid` | 失败分支地址列表 |
| `--stdin FILE` | 保存解出的输入内容 |

## 输出

```
flag/stdin : b'flag{...}'
stdout     : b'Correct!'
```
