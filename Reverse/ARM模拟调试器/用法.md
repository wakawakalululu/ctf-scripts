# arm_dbg 使用说明

> 来源: [SourceLizi/ctf-toolbox](https://github.com/SourceLizi/ctf-toolbox)(已移除 hexdump 依赖)

## 依赖

```
pip install unicorn capstone
```

## 命令

```bash
python arm_dbg.py --demo        # 运行内置 Thumb 示例并进入调试器
```

实战: 编辑脚本底部 `run_demo()` 的 `THUMB` 变量与 `mem_map`/`mem_write` 段, 替换成题目代码后同样运行。

## 调试器内命令

| 命令 | 说明 |
|------|------|
| `set reg <reg> <value>` | 写寄存器, 如 `set reg R0 0x37` |
| `set bpt <addr>` | 下断点 |
| `s` | 单步 |
| `n` | 步过(跳到下一条指令地址) |
| `r` | 运行到下一个断点 |
| `dump <addr> <size>` | hexdump 内存 |
| `list bpt` / `del bpt <addr>` | 断点列表/删除 |
| `a` / `t` | ARM / THUMB 反汇编切换 |
| `f` | 显示最近 10 条执行流 |
| `stop` | 退出 |

## 输出

断点命中/单步时打印寄存器组与反汇编指令流; `dump` 打印内存 hexdump。
