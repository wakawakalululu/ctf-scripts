# shellcode 生成与解析 使用说明

> 来源: [SourceLizi/ctf-toolbox](https://github.com/SourceLizi/ctf-toolbox)(已修复 \xNN 补零)

## 依赖

```
pip install pwntools
# shellcode_parser 另需系统工具: sudo apt install nasm binutils (Linux/WSL)
```

## shellcode_generator(直接汇编, 不产生 ELF)

```bash
python shellcode_generator.py --test           # 自测输出格式
python shellcode_generator.py                  # 默认 i386 execve("/bin/sh")
python shellcode_generator.py --arch amd64     # 64 位
```

改脚本内 `I386_EXECVE_SH` / `AMD64_EXECVE_SH` 为自己的汇编。

## shellcode_parser(汇编 shellcode.s → ELF → 提取 shellcode)

```bash
python shellcode_parser.py                # 默认汇编当前目录 shellcode.s
python shellcode_parser.py -s mysc.s      # 指定源文件(生成 mysc ELF)
```

## 输出

```
shellcode generated, len:25
\x31\xc0\x50\x68\x2f\x2f\x73\x68...
```

`\xNN` 串直接粘进 exp; `shellcode_parser` 生成的同名 ELF 可用 gdb 调试。
