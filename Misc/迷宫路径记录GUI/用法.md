# maze_run 使用说明

> 来源: [SourceLizi/ctf-toolbox](https://github.com/SourceLizi/ctf-toolbox)(py3 已完善)

## 依赖

```
tkinter(Windows 自带; Linux: sudo apt install python3-tk)
```

## 命令

```bash
python maze_run.py                    # 打开 GUI
python maze_run.py --out path.txt     # 关闭窗口时自动保存记录
python maze_run.py --chars wasd       # 自定义四方向字符(顺序: 上 下 左 右)
```

## 操作

| 按键 | 动作 |
|------|------|
| ↑ ↓ ← → | 在大文本框里把迷宫内容粘进去, 光标沿迷宫移动, 顶部实时记录方向字符 |
| Esc | 清空记录 |
| 关闭窗口 | `--out` 时把记录写入文件, 并在终端打印 |

## 输出

顶部输入框/输出文件中为方向字符序列(默认 `wasd`), 直接放进题目要求的提交格式。
