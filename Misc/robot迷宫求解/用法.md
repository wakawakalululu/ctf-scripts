# robot_maze 使用说明

> 来源: [0xaww/robot_maze](https://github.com/0xaww/robot_maze)(py2) → 已移植 py3 并修复越界/采样 bug

## 依赖

```
pip install pillow        # 仅图片功能需要; 纯文本求解无需依赖
```

## 命令

```bash
# 自测
python robot_maze.py --selftest

# 求解文本迷宫(默认: 墙#, 路空格, 起*, 终D)
python robot_maze.py --solve maze.txt

# 自定义字符集与方向输出
python robot_maze.py --solve maze.txt --move UDLR --wall 0 --path 1 --begin 2 --end 3

# 起终点不在标记内时用坐标指定(支持负数=从末尾倒数)
python robot_maze.py --solve maze.txt --start 1,1 --end -2,-2

# 图片迷宫(每个格子为等大色块)
python robot_maze.py --pic maze.png --start 1,1 --end -2,-2

# 生成随机迷宫
python robot_maze.py --gen 21 --out maze.txt          # 文本
python robot_maze.py --gen 21 --out maze.png --picgen # 图片
```

## 参数

| 参数 | 说明 |
|------|------|
| `--solve TXT` | 求解文本迷宫, 输出最短路径(步数+方向串) |
| `--pic PNG` | 求解图片迷宫, 需 `--start`/`--end` |
| `--start X,Y` / `--end X,Y` | 起终点坐标 |
| `--move UDLR` | 输出方向字符映射(上/下/左/右) |
| `--wall/--path/--begin/--dst` | 迷宫字符定义 |
| `--gen SIZE` | 生成 SIZE×SIZE 迷宫(`--picgen` 出 PNG) |
| `--selftest` | 内置自测 |

## 作为库调用(交互式探路模式)

```python
from robot_maze import Robot

robot = Robot(mode="all", move={"up": "U", "down": "D", "left": "L", "right": "R"})
while not robot.all_finish:
    step = robot.next_step()      # 探测点方向序列
    if 命中终点:
        robot.set_point(8)
    elif 撞墙:
        robot.set_point(0)
    else:
        robot.set_point(1)
print("".join(robot.min_output))  # 起点到终点最短路径
```
